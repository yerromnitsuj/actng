# Generalized diagnostic formula catalog

> Generated by `npm run docs:diagnostics`; do not edit by hand.

A formula is basis-independent arithmetic over typed roles. An instance binds those roles to caller-declared measures and adds presentation and review rules. Capping, gross/net treatment, expenses, exposure basis, and count population belong to measures/bases and bindings—not to duplicate formulas.

Every division is ratio-of-sums at the selected cell grain. A missing numerator or denominator, or a non-positive denominator, produces `null`; the SDK never emits `NaN` or silently averages row ratios.

## Caller-owned capped basis example

Define measures such as `paid-primary-250k` and `incurred-primary-250k` with an `AmountBasisDefinition` whose component limitation records the attachment, limit, application level, and derivation. Bind those measures to the ordinary `paid-to-incurred`, `amount-per-exposure`, `amount-per-claim`, and `case-per-open` templates. The same formulas then serve unlimited, capped, gross, net, or ceded bases while calculation fingerprints remain distinct.

## Identity scopes

- Formula identity covers only the reusable role/arithmetic contract.
- Calculation identity adds bindings, dependent measure semantics, populations/bases, derivations, and row grain.
- Definition identity adds presentation, instance rules, review rules, period axis, and the full catalog.
- Rule-only dependencies appear in semantic evaluation references without changing numeric calculation identity.
